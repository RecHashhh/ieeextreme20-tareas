Your first task is to write a program that outputs a message you'd like to say to the IEEEXtreme team,  and submit it to the system.  



#2 Standard input

Nothing on standard input.

#2 Standard output

Output a text with your message to us. The message should contain no more than $$200$$ words.

#2 Constraints and notes

- This task will *not* be scored and it is *optional*. 

- This "Constraints and notes" section is very important for each challenge. Please make sure that you read them.

- Please do take the time to write a message. We look forward to hearing from you!

#2 Locked editor and AI usage
- Most challenges are marked *Locked editor* in the list of challenges. Your code for them has to be written in our editor: only text that came out of your own workspace can be pasted into it, and the editor records how your solution is written. AI usage is *not* allowed on these challenges.
- The game challenges have an unlocked editor, and AI usage is allowed on them.
- This task uses the locked editor, so you can try it out here before the other challenges appear. Click its *Locked editor* label in the list of challenges for exactly what is and is not recorded, and how to bring in code you wrote before the contest.
#2 Technical notes on Python

In this competition, if you are working with Python2 or Python3, it is recommended that you submit your solution using Pypy2 or Pypy3. Pypy runs much faster than the regular Python interpreter and may sometimes help avoid Time Limit Exceeded for an algorithm that has an expected time complexity.
